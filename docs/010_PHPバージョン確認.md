# 010_PHPバージョン確認

## 目的

さくらのレンタルサーバーへCardCMSを置く前に、
PHPバージョンがCardCMSに合っているか確認する。

## CardCMS側の目安

- 推奨: PHP 8.2以上
- 利用可能目安: PHP 8.0以上
- 要確認: PHP 7系以下

CardCMSはPHPで動くため、古いPHPでは動作やセキュリティ面で不安が残る。

## ローカル環境

2026-07-20時点のローカル環境:

```text
PHP 8.5.8
```

ローカル環境ではCardCMSは問題なく動作している。

## さくらサーバー側で見る場所

さくらのサーバーコントロールパネルで確認する。

```text
サーバーコントロールパネル
→ スクリプト設定
→ 言語バージョン設定
→ PHPのバージョン
```

ログイン時は、メールアドレスではなく、
初期ドメインまたは追加されたドメインでログインする。

参考:

- https://help.sakura.ad.jp/rs/2241/
- https://help.sakura.ad.jp/rs/2256/

## CardCMS上での確認方法

テストアップロード後、管理画面へログインして確認する。

```text
https://ichiba-kogei.sakura.ne.jp/cardcms-test/admin/settings.php
```

この画面の「PHPバージョン」と「PHP判定」を確認する。

## 注意

PHPバージョンを変更した場合は、必ず次を確認する。

1. 公開ページが表示される
2. 管理画面へログインできる
3. カード一覧が表示される
4. カードの追加・編集・削除ができる
5. 画像が表示される
