# 007_さくらアップロード前チェックリスト

## 目的

CardCMSをさくらのレンタルサーバーへ安全にアップロードする前に確認する項目をまとめる。

## 予定ドメイン・フォルダ

- ドメイン名: ichiba-kogei.sakura.ne.jp
- 公開フォルダ: www
- テスト用フォルダ案: www/cardcms-test

## 基本方針

- いきなり www 直下へ本番公開しない
- まず www/cardcms-test にアップロードして表示を確認する
- パスワードはチャットやGitHubに書かない
- .git や .DS_Store はアップロードしない
- database/cards.json はブラウザから直接読ませない
- admin画面はログイン保護する
- apiもログイン後だけ動くようにする
- テスト公開中はGoogle検索に登録されないように noindex を入れる

## アップロード対象

- .htaccess
- index.php
- admin
- api
- config
- database
- includes
- public
- uploads

## アップロードしないもの

- .git
- .gitignore
- .DS_Store
- docs/.DS_Store
- assets/.DS_Store
- public/.DS_Store
- docs
- assets
- images
- CardCMS起動.command
- README.md
- backup
- config/auth.example.php

## 本番前に必要な安全対策

### 完了

- 公開ページはPHP側で cards.json を読み込み、公開中カードだけを表示する
- public側へ渡すカード情報は、表示に必要な項目だけに絞る
- database フォルダに .htaccess を置き、直接アクセスを拒否する準備を行う
- admin画面のログイン保護の仕組みを追加する
- apiにも同じログイン保護を追加する
- `config/auth.php` をGit管理から外す
- ローカル専用の初期設定ページを追加する
- config フォルダに直接アクセス拒否用 .htaccess を置く
- `config/auth.php` の作成を確認する
- `config/auth.php` がGit管理対象外であることを確認する
- 管理画面へのログイン動作を確認する
- ログアウト後にログイン画面へ戻ることを確認する
- テスト用入口としてルートの index.php を追加する
- ルートの .htaccess でフォルダ一覧表示を防止する
- includes フォルダに直接アクセス拒否用 .htaccess を置く
- www/cardcms-test 用のアップロード構成を整理する
- アップロード対象が42ファイルであることを確認する
- 管理画面のシステム情報にPHP判定を追加する
- CardCMS表示バージョンを Version 1.4 に更新する
- PHPバージョン確認メモを作成する
- テストアップロード用フォルダを作成する
- テストアップロード用ZIPを作成する
- ZIP内に不要なMac補助ファイルが入っていないことを確認する
- アップロード用フォルダでローカル動作確認を行う
- テスト版に noindex を追加する
- さくらテスト環境で公開ページが `200 OK` で開くことを確認する
- さくらテスト環境で管理画面がログイン画面へ戻ることを確認する
- さくらテスト環境で `database/cards.json` が外部から直接見えないことを確認する
- 管理画面にお問い合わせメール設定確認画面を追加する
- さくらテスト環境へお問い合わせメール設定確認画面を反映する

### 未完了

- さくら側管理画面で「お問い合わせメール設定」と「カード一覧のメニューへ戻る」を目視確認する
- 正式な送信先、BCC、送信元、返信先メールアドレスを先方に確認する
- 正式メール設定で送信確認を行う
- さくらサーバー上でのPHPバージョン確認

## 本番公開時に必ず確認すること

- `public/includes/header.php` の noindex 設定を外す
- `<meta name="robots" content="noindex, nofollow">` が残っていないことを確認する
- `X-Robots-Tag: noindex, nofollow` が出ていないことを確認する
- 本番公開後に sitemap.xml と robots.txt を整える
- Google Search Console で本番URLを確認する

## テスト時の確認URL案

- 公開ページ: https://ichiba-kogei.sakura.ne.jp/cardcms-test/public/index.php
- 公開ページ入口: https://ichiba-kogei.sakura.ne.jp/cardcms-test/
- 管理画面: https://ichiba-kogei.sakura.ne.jp/cardcms-test/admin/index.php
