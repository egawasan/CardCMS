# 007_さくらアップロード前チェックリスト

## 目的

CardCMSをさくらのレンタルサーバーへ安全にアップロードする前に確認する項目をまとめる。

## 予定ドメイン・フォルダ

- ドメイン名: ichiba-kogei.sakura.ne.jp
- 公開フォルダ: www
- テスト用フォルダ案: www/cardcms-test

## 基本方針

- いきなり www 直下へ本番公開しない
- まず www/cardcms-test にアップロードして表示を確認する
- パスワードはチャットやGitHubに書かない
- .git や .DS_Store はアップロードしない
- database/cards.json はブラウザから直接読ませない
- admin画面はログイン保護する
- apiもログイン後だけ動くようにする

## アップロード対象

- admin
- api
- assets
- database
- public
- uploads
- README.md

## アップロードしないもの

- .git
- .DS_Store
- docs/.DS_Store
- assets/.DS_Store
- public/.DS_Store
- backup

## 本番前に必要な安全対策

### 完了

- 公開ページはPHP側で cards.json を読み込み、公開中カードだけを表示する
- public側へ渡すカード情報は、表示に必要な項目だけに絞る
- database フォルダに .htaccess を置き、直接アクセスを拒否する準備を行う
- admin画面のログイン保護の仕組みを追加する
- apiにも同じログイン保護を追加する
- `config/auth.php` をGit管理から外す

### 未完了

- `config/auth.php` の作成
- 実際の管理画面パスワード設定
- ログイン動作確認
- さくらサーバー上でのPHPバージョン確認
- テストURLでの表示確認

## テスト時の確認URL案

- 公開ページ: https://ichiba-kogei.sakura.ne.jp/cardcms-test/public/index.php
- 管理画面: https://ichiba-kogei.sakura.ne.jp/cardcms-test/admin/index.php
