# CardCMS API設計書

CardCMSの管理画面から呼び出す処理を記録する。

---

## move_card.php

### 目的

カード一覧画面から、カードの表示順を上へ・下へ移動する。

### 呼び出し例

```text
../api/move_card.php?id=1784031902&direction=up
../api/move_card.php?id=1784031902&direction=down
```

### 処理内容

- `id` で対象カードを探す
- `direction` が `up` の場合は1つ上のカードと入れ替える
- `direction` が `down` の場合は1つ下のカードと入れ替える
- 入れ替え後、`sort_order` を `10 / 20 / 30 ...` の形に整え直す
- 処理後はカード一覧画面へ戻る

### 備考

公開ページの表示順は `sort_order` に従う。
