# CardCMS PROJECT STATUS

## プロジェクト概要

CardCMSを実用レベルのCMSへ育て、
管理中のWordPressサイト（https://ichiba-k.jp）を
CardCMSへ移行すること。

----------------------------------------

## CardCMS設計思想

CardCMSは、

**1枚のカード = 1つの情報ブロック**

を基本思想とする。

カードを順番に並べることでホームページを構成する。

WordPressのように「ページ」を中心に考えるのではなく、
「カード」を積み重ねてサイト全体を構築するCMSを目指す。

## 開発方針

・理解しながら進める
