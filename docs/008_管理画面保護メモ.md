# 008_管理画面保護メモ

## 目的

さくらのレンタルサーバーへアップロードする前に、
CardCMSの管理画面を誰でも開けないようにする。

## 方針

- admin画面はログイン後だけ開ける
- apiもログイン後だけ動く
- パスワードそのものはGitHubへ入れない
- パスワードそのものはチャットにも書かない
- 実際の設定は `config/auth.php` に保存する
- `config/auth.php` は `.gitignore` でGit管理から外す

## 追加したファイル

- `includes/auth.php`
  - ログイン状態を確認する共通ファイル
- `admin/login.php`
  - 管理画面ログインページ
- `admin/logout.php`
  - ログアウトページ
- `config/auth.example.php`
  - 設定ファイルの見本

## 未設定時の動き

`config/auth.php` がまだない場合、
admin画面は開かず、ログイン画面に
「管理画面保護の設定が必要です」と表示される。

これは、本番公開時に管理画面が無防備にならないようにするためである。

## 次に必要な作業

1. `config/auth.example.php` を参考に `config/auth.php` を作る
2. 管理画面用ユーザー名を決める
3. 管理画面用パスワードを決める
4. パスワードを `password_hash` でハッシュ化して保存する
5. ログインできるか確認する

## 注意

パスワードをこのメモ、GitHub、チャットに書かない。
パスワードの入力が必要な場面では、江川さん側で直接入力する。
