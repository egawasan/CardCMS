# お問い合わせフォーム

## 目的

現行サイトの簡単なお問い合わせフォームを参考に、
CardCMSの公開ページへお問い合わせフォームを追加する。

## フォーム項目

現行サイトに合わせ、次の5項目を扱う。

- お名前
- 電話番号
- 住所
- メールアドレス
- お問い合わせ内容

すべて必須項目とする。

## 画面の流れ

1. 入力画面
2. 入力チェック
3. 確認画面
4. 送信完了画面
5. 管理者宛メール送信
6. お客様宛の自動返信メール送信

## 追加ファイル

- `public/contact.php`
- `config/contact.example.php`
- `admin/contact_settings.php`

## 設定ファイル

実際の送信先メールアドレスは、次のファイルで設定する。

```text
config/contact.php
```

このファイルはGitHubへ送らない。

設定例は次のファイルに置く。

```text
config/contact.example.php
```
