# CardCMS作業日誌

この日誌はCardCMS開発の記録である。

Version1.0からGitHubによるバージョン管理を開始し、
WordPressサイト（https://ichiba-k.jp）のCardCMSへの移行を目標として、
日々の開発内容を記録する。

---

## 2026-07-17

### Version 1.3 仕上げ作業

【本日の作業】

・文章部分に薄い背景色を追加
・本文パネルの文字色、余白、枠線を調整
・紹介文カードを元サイトに近い濃い青背景と白文字に調整
・カテゴリーは管理用情報として残し、public側では表示しないようにした

【成果】

・文章部分がカード内でまとまり、元サイトの雰囲気に少し近づいた
・背景色と文字色をCSSだけで調整できる第一段階ができた
・必要であれば、今後カードごとに背景色を変える方向へ発展できる
・公開ページからカテゴリー名が消え、トップページらしい見た目に近づいた

【次回予定】

・表示を見ながら背景色と文字色を微調整する
・画像をCardCMS内に取り込む方針を決める
・お問い合わせフォームは本番前に改めて検討する

## 2026-07-15

### Version 1.3 継続

【本日の作業】

・前回までの状態を確認
・公開ページのカード本文の文字サイズを調整
・見出しの文字サイズ、余白、下線を調整

・複数画像用に `images` 項目を追加
・公開ページで代表画像と追加画像を縦に並べて表示できるようにした
・新規カード画面と編集画面に追加画像入力欄を追加
・制作・施工・点検、保守点検についてのカードに追加画像を設定
・管理画面の画像プレビューを外部URL画像にも対応
・本文を通常文章、箇条書き、項目表示として読み分ける表示処理を追加
・新規カード画面と編集画面の本文欄に、簡単な入力ルールを表示
・公開ページの本文、見出し、カテゴリーの文字サイズを一段大きく調整
・スマホ表示で複数画像の間隔が広く見える問題を調整
・管理画面のカード一覧を表示順で並べるように変更

・本社・工場カードに Googleマップリンクを追加

・元サイト内の地図2箇所は、同じ本社・工場のGoogleマップとして扱う方針にした

【成果】

・カードを上から下へ積み重ねる基本方針はそのままに、文章が読みやすくなった
・特殊フォントを使わず、標準フォントのまま文字サイズと行間で見やすさを改善できた
・複数画像を持つカードを表示できる第一段階ができた
・今後、複数アップロード機能へ発展させる土台ができた
・本文欄を複雑にせず、入力内容に合わせて表示を整える土台ができた
・現在の公開ページに近い読みやすい文字サイズへ調整できた
・複数画像がスマホでも詰まりよく縦に並ぶようになった
・管理画面からカードを上へ下へ積み替えられるようになった
・スペースで揃えなくても、項目名と内容が自然に並ぶ表示になった
・地図は埋め込みではなく、まずは「Googleマップで見る」リンクとして扱えるようになった
・同じ地図を2回表示せず、本社・工場カードに集約する方針を決められた

【次回予定】
