# CardCMS作業日誌

この日誌はCardCMS開発の記録である。

Version1.0からGitHubによるバージョン管理を開始し、
WordPressサイト（https://ichiba-k.jp）のCardCMSへの移行を目標として、
日々の開発内容を記録する。

---

## 2026-07-14

### Version 1.3 開始

【本日の作業】

・PROJECT_STATUS.md を確認
・現在のWordPressトップページを確認
・トップページの大きな構成を整理
・docs/005_WordPressトップページ移植メモ.md を作成
・公開ページに市場工芸のロゴを表示
・公開ページにメイン画像を表示
・トップ紹介文を固定HTMLとして移植
・下部固定メニューの下準備
・本社・工場とお問い合わせの簡易欄を追加
・ヘッダー、メイン画像、本文、フッター、固定メニューの横幅基準を共通化
・カード種別とレイアウトの設計方針を整理
・cards.json の正式なカード形式を設計書に追記
・新規カード画面にカード種別を追加
・新規カード画面にレイアウトを追加
・編集画面と一覧画面にもカード種別とレイアウトを表示
・保存処理と更新処理で card_type と layout を扱えるようにした
・新規カード画面に管理名（slug）を追加
・編集画面と一覧画面にも管理名（slug）を表示
・保存処理と更新処理で slug を扱えるようにした
・新規保存時に created_at と updated_at を自動保存するようにした
・編集保存時に updated_at を自動更新するようにした
・編集画面と一覧画面で日時を確認できるようにした
・公開ページで Text レイアウトのカードは画像枠を表示しないようにした
・既存カードデータを新しい形式へ整理
・既存カードの表示順を 10 / 20 / 30 に整理
・公開ページに ImageLeft、ImageRight、Gallery、Text の基本表示スタイルを追加
・docs/006_トップページカード設計表.md を作成
・トップページ主要ブロックをカード単位で整理

【成果】

・Version 1.3 で移植する対象を整理できた
・いきなり実装せず、まず移植方針を確認できる状態にした
・トップページの外側を市場工芸向けに近づけた
・スマホでも使いやすい固定メニューの土台ができた
・大きい画面でも左右幅がそろいやすくなった
・カードを積み重ねてページを作るCardCMSらしい設計が明確になった
・管理画面からカードの用途と表示方法を指定できる土台ができた
・カードを安定して呼び出すための管理名を保存できるようになった
・カードの作成日時と更新日時を記録できるようになった
・画像なしの文章カードを自然に表示する第一段階ができた
・既存カードデータの形式がそろい、次のレイアウト表示調整に進みやすくなった
・レイアウトごとにカードの見た目を変える第一段階ができた
・WordPressトップページの主要ブロックをCardCMSのカードとして整理できた

【次回予定】

・トップページ用カードを1枚ずつ実データとして登録する
・各カードに使う代表画像を決める
・公開ページ側で Hero と Contact の表示方針を決める
