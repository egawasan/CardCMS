# CardCMS CHANGELOG

このファイルは CardCMS の開発履歴を記録します。

---

## Version 1.0（2026-07-13）

### 完成内容
- CardCMS の基本機能を一通り使える状態に整理
- 管理メニュー、新規カード、カード一覧、編集、削除、画像管理、システム情報、公開ページを接続
- 画面下部のバージョン表示を Version 1.0 に統一
- README.md に起動方法、主な画面、現在の機能を記録

### 完了
- CardCMS 基本版を Version 1.0 として区切った

---

## Version 0.13（2026-07-13）

### 不具合修正
- 新規カード画面と編集画面の「戻る」ボタンが動作しない問題を修正

### 完了
- 「戻る」ボタンからカード一覧へ戻れるようになった

---

## Version 0.12（2026-07-13）

### 新機能
- 画像管理画面を追加
- uploads フォルダ内の画像を一覧表示
- 画像のファイル名、サイズ、更新日を表示
- どのカードで画像が使われているかを表示
- メニュー画面から画像管理画面へ移動できるようにした

### 完了
- アップロード済み画像を管理画面から確認できるようになった

---

## Version 0.11（2026-07-13）

### 不具合修正
- 画像未登録カードの編集画面で `htmlspecialchars()` の警告が表示される問題を修正

### 完了
- 画像が未登録でも編集画面を正常に表示できるようになった

## Version 0.8（2026-07-12）

### 新機能
- 公開ページにカード一覧を表示
- published が true のカードだけを表示
- sort_order と id を使って表示順を整理
- 画像があるカードは uploads フォルダの画像を表示
- 画像がないカードには「画像なし」を表示
- 管理画面から公開ページを開くリンクを追加

### 完了
- public/index.html で公開中カードを確認できるようになった
- 管理画面のカード一覧で画像列とタイトル列の表示を整理
