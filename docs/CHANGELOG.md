# CardCMS CHANGELOG

このファイルは CardCMS の開発履歴を記録します。

---

## Version 1.3（2026-07-14〜2026-07-15）

### 改善
- WordPressトップページの構成を確認し、移植メモを作成
- 公開ページのヘッダーに市場工芸のロゴを表示
- 公開ページにメイン画像を表示
- トップ紹介文を固定HTMLとして追加
- 公開ページの見出しを「カード一覧」から「お知らせ」へ変更
- 下部固定メニューの下準備として「本社・工場」「メール」「電話」を追加
- 固定メニューのリンク先として、本社・工場とお問い合わせの簡易欄を追加
- ヘッダー、メイン画像、本文、フッター、固定メニューの横幅基準を共通化
- カード番号を内部管理用とし、カード種別とレイアウトで表示用途を判断する方針を追加
- `card_type`、`layout`、`slug`、`created_at`、`updated_at` を含むカードJSON形式を設計書に追加
- 新規カード画面、編集画面、一覧画面にカード種別とレイアウトを追加
- 保存処理と更新処理で `card_type` と `layout` を扱えるようにした
- 新規カード画面、編集画面、一覧画面に管理名（slug）を追加
- 保存処理と更新処理で `slug` を扱えるようにした
- 新規保存時に `created_at` と `updated_at` を自動保存するようにした
- 編集保存時に `updated_at` を自動更新するようにした
- 編集画面と一覧画面で日時を確認できるようにした
- 公開ページで `layout` が `Text` のカードは画像枠を表示しないようにした
- 既存カードデータを `card_type`、`layout`、`slug`、`created_at`、`updated_at` を含む形式へ整理
- 既存カードの表示順を `10 / 20 / 30` に整理
- 公開ページで `ImageLeft`、`ImageRight`、`Gallery`、`Text` の基本表示スタイルを追加
- トップページを構成する主要情報ブロックのカード設計表を作成
- 固定HTMLだったメイン画像を `main-visual` のHeroカードへ移行
- `top-intro` カードを正式な紹介文カードとして更新
- `house-cleaning` カードを追加
- `main-visual` は本文を空にし、画像だけのHeroカードとして表示
- `house-cleaning` カードに代表画像と本文を設定
- `infection-control` カードを追加
- ImageLeft / ImageRight の画像を切れにくい表示へ調整
- 公開ページのカードを左右横並びではなく、上から下へ縦に積む表示へ調整
- 通常カードはタイトル・本文を先に表示し、その下に画像を表示する形へ変更
- 公開ページの本社・工場、お問い合わせの固定HTMLを外し、カード表示へ移行
- 残りのトップページ主要カードを追加
- 固定メニューのリンク先を、本社・工場カードとお問い合わせカードへ変更
- 公開ページのカード本文、見出し、行間、余白を読みやすく調整
- カードに追加画像一覧 `images` を持たせる方針を追加
- 公開ページで代表画像と追加画像を縦に並べて表示できるようにした
- 新規カード画面と編集画面に追加画像入力欄を追加
- 制作・施工・点検、保守点検についてのカードに追加画像を設定
- 管理画面の画像プレビューを外部URL画像にも対応

### 完了
- WordPressトップページ移植の第一段階として、ロゴ・メイン画像・トップ紹介文を表示できるようになった
- スマホでも使いやすい固定メニューの土台ができた
- カードを積み重ねてページを作るCardCMSらしい設計方針が明確になった
- 管理画面からカードの用途と表示方法を指定する土台ができた
- カードに管理用の識別名を持たせる土台ができた
- カードの作成日時と更新日時を記録できるようになった
- 画像なしの文章カードを自然に表示する第一段階ができた
- 既存カードデータの形式をそろえ、次のレイアウト表示調整に進みやすくなった
- レイアウトごとにカードの見た目を変える第一段階ができた
- WordPressトップページの主要ブロックをCardCMSのカードとして整理できた
- トップページの先頭3ブロックをカードとして扱う形にできた
- メイン画像と紹介文の役割をカード単位で分けられた
- ハウスクリーニングと感染症対策をサービスカードとして表示できるようになった
- 元サイトのように、カードを縦に積み重ねてトップページを作る方向へ表示を修正できた
- トップページの主要ブロックを、ひとまずすべてカードとして並べられる状態になった
- 文字まわりの第一段階調整により、公開ページのカード本文が読みやすくなった
- 複数画像を持つカードを表示できる第一段階ができた
