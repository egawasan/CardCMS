# 011_テストアップロード手順

## 目的

作成したCardCMSを、さくらのレンタルサーバーへテストアップロードする手順を整理する。

## 作成済みアップロード用ファイル

デスクトップに次を作成した。

```text
/Users/egawakiyoo/Desktop/CardCMS_upload/cardcms-test/
/Users/egawakiyoo/Desktop/CardCMS_upload/cardcms-test.zip
```

## 確認済み内容

- アップロード用フォルダ内のPHP構文チェック: OK
- `config/auth.php` の認証設定: 有効
- `database/cards.json` のカード件数: 13件
- アップロード用フォルダのファイル数: 42ファイル
- ZIP内に `.DS_Store` や `._` 補助ファイルが入っていないことを確認
- ローカル一時サーバーで入口URLから公開ページへ移動することを確認
- ローカル一時サーバーで管理画面ログインページが表示されることを確認
- ローカル一時サーバーで未ログイン時のadmin保護が動くことを確認

## サーバー側の設置先

さくらサーバーでは、次の形になるように置く。

```text
www/
└── cardcms-test/
    ├── index.php
    ├── admin/
    ├── api/
    ├── config/
    ├── database/
    ├── includes/
    ├── public/
    └── uploads/
```

## ZIPでアップロードする場合

`cardcms-test.zip` を `www` にアップロードして展開する。

展開後に、次の形になっていればよい。

```text
www/cardcms-test/index.php
```

次のように二重になっていたら間違い。

```text
www/cardcms-test/cardcms-test/index.php
```

## フォルダごとアップロードする場合

`cardcms-test` フォルダを `www` の中へアップロードする。

結果として、次の形になればよい。

```text
www/cardcms-test/
```

## 注意

`cardcms-test.zip` と `cardcms-test/config/auth.php` には管理画面の認証設定が含まれる。

パスワードそのものではないが、重要な設定ファイルなので、
メール添付や不要な共有はしない。
