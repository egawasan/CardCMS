# CardCMS データベース設計書

Version 0.1

---

## 1. データベース概要

CardCMSではSQLiteを採用する。

理由

- サーバー設定が容易
- バックアップが簡単
- 小～中規模システムに適している
- 将来の業務システムにも対応できる

---

## 2. cardsテーブル

|項目名|型|必須|内容|
|------|---|---|------|
|id|INTEGER|○|カードID（主キー）|
|title|TEXT|○|タイトル|
|body|TEXT|○|本文|
|image|TEXT||画像ファイル名|
|category|TEXT||カテゴリー|
|sort_order|INTEGER||表示順|
|published|INTEGER|○|公開状態（0:非公開、1:公開）|
|created_at|TEXT|○|作成日時|
|updated_at|TEXT|○|更新日時|
